# External SharePoint Access (1440 Marketing External)

## Instructions

1. Open the SharePoint Online email invitation (from `no-reply@sharepointonline.com`) and select **Go To 1440 Marketing External**.


![Page 1](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/External_SharePoint_access/pages/page_1.png?st=2026-01-19T20%3A36%3A09Z&se=2027-01-19T20%3A41%3A09Z&sp=r&sv=2026-02-06&sr=b&sig=SZSPk9RPXhMfhHoSlEs0ZSZwNu4%2BBKdxvrw9NXthWmg%3D)

2. If the email shows a privacy banner indicating external images were not downloaded, select **Download external images** (if needed) so the email content displays correctly.


![Page 1](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/External_SharePoint_access/pages/page_1.png?st=2026-01-19T20%3A36%3A09Z&se=2027-01-19T20%3A41%3A09Z&sp=r&sv=2026-02-06&sr=b&sig=SZSPk9RPXhMfhHoSlEs0ZSZwNu4%2BBKdxvrw9NXthWmg%3D)

3. If prompted with **More information required**, select **Next** to continue.


![Page 2](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/External_SharePoint_access/pages/page_2.png?st=2026-01-19T20%3A36%3A09Z&se=2027-01-19T20%3A41%3A09Z&sp=r&sv=2026-02-06&sr=b&sig=grkfawu6B/xtFLrad4Uczt7VDHNeSCGV704cyL5HI7c%3D)

4. On the Microsoft **Sign in** screen, select **Send code** (this sends a sign-in code to your email).


![Page 2](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/External_SharePoint_access/pages/page_2.png?st=2026-01-19T20%3A36%3A09Z&se=2027-01-19T20%3A41%3A09Z&sp=r&sv=2026-02-06&sr=b&sig=grkfawu6B/xtFLrad4Uczt7VDHNeSCGV704cyL5HI7c%3D)

5. Enter the emailed code on the **Enter code** screen, then select **Sign in**.


![Page 2](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/External_SharePoint_access/pages/page_2.png?st=2026-01-19T20%3A36%3A09Z&se=2027-01-19T20%3A41%3A09Z&sp=r&sv=2026-02-06&sr=b&sig=grkfawu6B/xtFLrad4Uczt7VDHNeSCGV704cyL5HI7c%3D)

6. When you see **Permissions requested by: 1440 Foods**, review the prompt and select **Accept** to proceed.


![Page 2](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/External_SharePoint_access/pages/page_2.png?st=2026-01-19T20%3A36%3A09Z&se=2027-01-19T20%3A41%3A09Z&sp=r&sv=2026-02-06&sr=b&sig=grkfawu6B/xtFLrad4Uczt7VDHNeSCGV704cyL5HI7c%3D)

7. If the **Keep your account secure** flow starts, follow the Microsoft Authenticator setup screens. On **Start by getting the app**, install Microsoft Authenticator (if needed) and select **Next**.


![Page 3](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/External_SharePoint_access/pages/page_3.png?st=2026-01-19T20%3A36%3A09Z&se=2027-01-19T20%3A41%3A09Z&sp=r&sv=2026-02-06&sr=b&sig=1GFFQv43K2nd0jR1PU2IorA4d3A%2BqwBBXdlaNU4TH9M%3D)

8. On **Set up your account**, select **Next**.


![Page 3](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/External_SharePoint_access/pages/page_3.png?st=2026-01-19T20%3A36%3A09Z&se=2027-01-19T20%3A41%3A09Z&sp=r&sv=2026-02-06&sr=b&sig=1GFFQv43K2nd0jR1PU2IorA4d3A%2BqwBBXdlaNU4TH9M%3D)

9. On **Scan the QR code**, use the Microsoft Authenticator app to scan the QR code, then select **Next**. (A **Can’t scan image?** option may be available.)


![Page 3](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/External_SharePoint_access/pages/page_3.png?st=2026-01-19T20%3A36%3A09Z&se=2027-01-19T20%3A41%3A09Z&sp=r&sv=2026-02-06&sr=b&sig=1GFFQv43K2nd0jR1PU2IorA4d3A%2BqwBBXdlaNU4TH9M%3D)

10. On **Let’s try it out**, approve the notification by entering the number shown on the screen in your Authenticator app.


![Page 4](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/External_SharePoint_access/pages/page_4.png?st=2026-01-19T20%3A36%3A09Z&se=2027-01-19T20%3A41%3A09Z&sp=r&sv=2026-02-06&sr=b&sig=aWg8RaL2TNRc31nFSyOqEAmdUpcfEn6VH/zGfHwitGM%3D)

11. After you see **Notification approved**, select **Next**.


![Page 4](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/External_SharePoint_access/pages/page_4.png?st=2026-01-19T20%3A36%3A09Z&se=2027-01-19T20%3A41%3A09Z&sp=r&sv=2026-02-06&sr=b&sig=aWg8RaL2TNRc31nFSyOqEAmdUpcfEn6VH/zGfHwitGM%3D)

12. On the **Success!** screen, select **Done** to continue signing in.


![Page 4](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/External_SharePoint_access/pages/page_4.png?st=2026-01-19T20%3A36%3A09Z&se=2027-01-19T20%3A41%3A09Z&sp=r&sv=2026-02-06&sr=b&sig=aWg8RaL2TNRc31nFSyOqEAmdUpcfEn6VH/zGfHwitGM%3D)

13. After sign-in completes, you should land on the SharePoint site **1440 Marketing External** (Document Center).


![Page 5](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/External_SharePoint_access/pages/page_5.png?st=2026-01-19T20%3A36%3A09Z&se=2027-01-19T20%3A41%3A09Z&sp=r&sv=2026-02-06&sr=b&sig=YBd7YMgKBDnoFLk4Mf93o4hSF9fflFhcLxxE1HsBWQg%3D)
