# Microsoft Multifactor Authentication (MFA) Setup Guide

## Instructions (Microsoft Authenticator)

**Step 1 — Accept the Microsoft invitation**  
Open the Microsoft invitation email and select **Accept invitation**.

  
![Accept invitation](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/1440-Microsoft_Multifactor_Authentication_Documentation/assets/Image_61b0.png?st=2026-01-19T20%3A33%3A58Z&se=2027-01-19T20%3A38%3A58Z&sp=r&sv=2026-02-06&sr=b&sig=goiVgAly5GRpRluvXs8kbWnxhI/RVFG9%2BMRNrEGSt4w%3D)

**Step 2 — Sign in with your password**  
Enter your password and select **Sign in**.

  
![Enter password and sign in](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/1440-Microsoft_Multifactor_Authentication_Documentation/assets/Image_564d.png?st=2026-01-19T20%3A33%3A56Z&se=2027-01-19T20%3A38%3A56Z&sp=r&sv=2026-02-06&sr=b&sig=xgxVPf7zt5kDeG0WX6jBVsFJkhVL6nX4vqUSMKDj%2B2o%3D)

**Step 3 — Accept the permissions request**  
On the **Permissions requested** screen, select **Accept**.

  
![Permissions requested — Accept](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/1440-Microsoft_Multifactor_Authentication_Documentation/assets/Image_3e6e.png?st=2026-01-19T20%3A33%3A56Z&se=2027-01-19T20%3A38%3A56Z&sp=r&sv=2026-02-06&sr=b&sig=f3zZ/1lY1mDoDITxInijBDF9Kif/%2BP/I3PPVRGN/TTY%3D)

**Step 4 — Start Microsoft Authenticator setup**  
On **Keep your account secure — Microsoft Authenticator**, select **Next** (and use **Show QR code** when prompted).

  
![Keep your account secure — Next](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/1440-Microsoft_Multifactor_Authentication_Documentation/assets/Image_ab05.png?st=2026-01-19T20%3A33%3A57Z&se=2027-01-19T20%3A38%3A57Z&sp=r&sv=2026-02-06&sr=b&sig=iyBsNYu5Hd6UA03mlhDLpLsGDMin%2B7uMDE05JXHgrR0%3D)

**Step 5 — Display the QR code on your computer**  
Select **Show QR code** to display the QR code.

  
![QR code shown on screen](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/1440-Microsoft_Multifactor_Authentication_Documentation/assets/Image_c0cf.png?st=2026-01-19T20%3A33%3A57Z&se=2027-01-19T20%3A38%3A57Z&sp=r&sv=2026-02-06&sr=b&sig=nb7exvchy0tbC5pBIJFQXRM4be2AY2KBnHXM3M%2Bd36w%3D)

**Step 6 — Add your work/school account in Microsoft Authenticator (phone)**  
In Microsoft Authenticator, choose **Work or school account**.

  
![Add account — Work or school account](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/1440-Microsoft_Multifactor_Authentication_Documentation/assets/Image_dfc8.png?st=2026-01-19T20%3A33%3A56Z&se=2027-01-19T20%3A38%3A56Z&sp=r&sv=2026-02-06&sr=b&sig=WCCXUgKCAlacEy5cqzBhP8nW1QUozHQLFbDqgKeLSt0%3D)

**Step 7 — Scan the QR code (phone)**  
Select **Scan QR code**, then scan the QR code displayed on your computer.

  
![Scan QR code option](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/1440-Microsoft_Multifactor_Authentication_Documentation/assets/Image_0ad0.png?st=2026-01-19T20%3A33%3A56Z&se=2027-01-19T20%3A38%3A56Z&sp=r&sv=2026-02-06&sr=b&sig=G4BIwEsY93EN0PsYmCC2DnFJZMgI5iJ%2BzdnY2uemlAM%3D)

**Step 8 — Approve the sign-in (number matching)**  
When prompted, approve the notification by entering the number shown on the screen.

  
![Approve by entering the number shown](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/1440-Microsoft_Multifactor_Authentication_Documentation/assets/Image_5d9c.png?st=2026-01-19T20%3A33%3A57Z&se=2027-01-19T20%3A38%3A57Z&sp=r&sv=2026-02-06&sr=b&sig=EyXu4VvGWNE6LicrKFQrk0F1E5ewU522MCxh0c1l%2BlI%3D)

## Instructions (Email Code Verification — if prompted)

**Step 1 — Request a security code by email**  
On **We need to verify your identity**, select **Email** and then select **Get code**.

  
![Verify identity — Get code](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/1440-Microsoft_Multifactor_Authentication_Documentation/assets/Image_0657.png?st=2026-01-19T20%3A33%3A57Z&se=2027-01-19T20%3A38%3A57Z&sp=r&sv=2026-02-06&sr=b&sig=bg2P9/5x9gPj%2BhTAePgeVETeuSNuTys0D1ROluHBpnE%3D)

**Step 2 — Use the Email code option during sign-in**  
Select **Email code** and continue the sign-in process.

  
![Email code option](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/1440-Microsoft_Multifactor_Authentication_Documentation/assets/Image_1c28.png?st=2026-01-19T20%3A33%3A57Z&se=2027-01-19T20%3A38%3A57Z&sp=r&sv=2026-02-06&sr=b&sig=GuZwBVaFYmSl4zPEs5r08Sgxfj7c6UXjc0/W9rqkYXY%3D)

## Frequently Asked Questions

- **What MFA methods can be added?** The **Add a method** menu shows: **Authenticator app**, **Email**, **Security key**, and **Office phone**.  

  ![Add a method options](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/1440-Microsoft_Multifactor_Authentication_Documentation/assets/Image_e3fc.png?st=2026-01-19T20%3A33%3A58Z&se=2027-01-19T20%3A38%3A58Z&sp=r&sv=2026-02-06&sr=b&sig=pXmjJVQHuv3DXBcARrDxNbVxtwV8JSAOFl/CFkGHLO4%3D)

- **What if I want a different verification method than Microsoft Authenticator?** The setup screen includes **I want to set up a different method**.  

  ![Different method option](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/1440-Microsoft_Multifactor_Authentication_Documentation/assets/Image_5d9c.png?st=2026-01-19T20%3A33%3A57Z&se=2027-01-19T20%3A38%3A57Z&sp=r&sv=2026-02-06&sr=b&sig=EyXu4VvGWNE6LicrKFQrk0F1E5ewU522MCxh0c1l%2BlI%3D)
