# Self Service Password Reset Guide (1440 Foods)

## Introduction

### Objective
To enhance security, 1440 Foods has strengthened the password requirements for Microsoft 365. Users will need to create a new password by completing the steps below. This process can also be used when a user has forgotten their password and needs to reset it without putting in a support ticket.

## Instructions

## Method 1: Reset via Web Browser

### Step 1: Open the password reset website
Go to the following website: https://passwordreset.microsoftonline.com/

### Step 2: Enter your email address and complete Captcha
Enter your 1440 email address and complete the Captcha. Click **Next**.

![aa89](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/processed_images/visual_aa89_page_4.png?st=2026-01-20T19%3A27%3A29Z&se=2027-01-20T19%3A32%3A29Z&sp=r&sv=2026-02-06&sr=b&sig=x8A7g9lS9DnoJlJj/1v%2BlxeE7grbN5FNqutLdD0Kpjo%3D)

### Step 3: Complete two-step verification (code to phone or email)
Complete two-step verification by entering a code sent to your phone or email.

![5db2](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/processed_images/visual_5db2_page_4.png?st=2026-01-20T19%3A27%3A29Z&se=2027-01-20T19%3A32%3A29Z&sp=r&sv=2026-02-06&sr=b&sig=0ZRvA8AjMPBL8Lu/9jOm5uO8dl0bap1KIy7CCTgeQgE%3D)

### Step 4: Complete verification using Microsoft Authenticator (if prompted)
Complete two-step verification using Microsoft Authenticator.

![f9bb](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/processed_images/visual_f9bb_page_5.png?st=2026-01-20T19%3A27%3A30Z&se=2027-01-20T19%3A32%3A30Z&sp=r&sv=2026-02-06&sr=b&sig=cR82M0VeKTiMlv6Uvb%2B7IVgP8Rkir8dtW1VguY9LPo8%3D)

**Note:** Number will be different from the example shown here.

![6742](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/processed_images/visual_6742_page_5.png?st=2026-01-20T19%3A27%3A30Z&se=2027-01-20T19%3A32%3A30Z&sp=r&sv=2026-02-06&sr=b&sig=5DAHjqMmtUqry4/OSeNkoWPSR7NcpvskvtwL9BD4xMY%3D)

### Step 5: Create a new password and finish
Select a new password. Click **Finish** to save your changes.

![a2dd](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/processed_images/visual_a2dd_page_5.png?st=2026-01-20T19%3A27%3A30Z&se=2027-01-20T19%3A32%3A30Z&sp=r&sv=2026-02-06&sr=b&sig=ab1BuKLW7SobnGbGM%2BlPwwptCRm5P6nvVw8NB2zWIyI%3D)

**Password requirements (per source):** Password must be at least **14 characters**, contain at least **one uppercase** and **one lowercase** letter, and at least **one number/special character**.

## Method 2: Reset Password on Your Laptop

### Step 1: Start reset from the lock screen
Click **Reset password** when asked to enter your password on your laptop's lock screen. Complete the Captcha and click **Next**.

![e679](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/processed_images/visual_e679_page_6.png?st=2026-01-20T19%3A27%3A30Z&se=2027-01-20T19%3A32%3A30Z&sp=r&sv=2026-02-06&sr=b&sig=iDt5sf2QyrI/3O797gLrPnkfmrJfaHlwkyOqZrl8XYs%3D)

### Step 2: Choose a contact method for verification
Select which contact method you want to use for account verification (**phone or email**) and enter your phone number or email address. Click **Next**.

![d938](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/processed_images/visual_d938_page_6.png?st=2026-01-20T19%3A27%3A30Z&se=2027-01-20T19%3A32%3A30Z&sp=r&sv=2026-02-06&sr=b&sig=q8FumOgo9yKCUFqU3QE5H7drq%2B7Hih8eh5me0ipy6U8%3D)

### Step 3: Enter the verification code
Enter the code delivered to your chosen contact method and click **Next**.

![a1b2](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/processed_images/visual_a1b2_page_6.png?st=2026-01-20T19%3A27%3A30Z&se=2027-01-20T19%3A32%3A30Z&sp=r&sv=2026-02-06&sr=b&sig=nOCzOvXLxZ3qTyMqqTJ1lYPb3eBvAPGHDPSIrSTNaaw%3D)

### Step 4: Complete verification using Microsoft Authenticator (if prompted)
Complete two-step verification using Microsoft Authenticator.

![adbd](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/processed_images/visual_adbd_page_7.png?st=2026-01-20T19%3A27%3A31Z&se=2027-01-20T19%3A32%3A31Z&sp=r&sv=2026-02-06&sr=b&sig=EVJ0knKQLPb9DuMHIslrv%2B/JF1Vy8BXegpq5yQQQrRM%3D)

**Note:** Number will be different from the example shown here.

### Step 5: Create a new password and finish
Select a new password. Click **Finish** to save your changes!

**Password requirements (per source):** Password must be at least **14 characters**, contain at least **one uppercase** and **one lowercase** letter, and at least **one number/special character**.
