# Accessing a SharePoint Document Shared with an External User (Outside WSNS)

Users from outside of WSNS must complete the steps below to access a file uploaded to SharePoint and shared externally.


## Instructions

### Step 1 — Accept the SharePoint invitation email and begin MFA setup
Accept the emailed invitation to the SharePoint site and set up Multi-Factor Authentication (MFA).

![46bb](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/processed_images/visual_46bb_page_1.png?st=2026-01-20T19%3A26%3A16Z&se=2027-01-20T19%3A31%3A16Z&sp=r&sv=2026-02-06&sr=b&sig=ZG5ys82Iva3goYO1TYMtISEXCZUfQjh5cOuOyqsJWJc%3D)


### Step 2 — Sign in and request a code to your email
Sign in to the SharePoint site by requesting a code to your email.

![a150](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/processed_images/visual_a150_page_2.png?st=2026-01-20T19%3A26%3A16Z&se=2027-01-20T19%3A31%3A16Z&sp=r&sv=2026-02-06&sr=b&sig=w7b/gHYabeMwd8DpFGyq1dAQDHU5YiG%2BASgs/9LnHGs%3D)


### Step 3 — Set up your authentication method (Authenticator app or text message)
Download the Microsoft Authenticator app **or** set up authentication via text message by clicking **“I want to set up a different method”**.

![fadf](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/processed_images/visual_fadf_page_2.png?st=2026-01-20T19%3A26%3A16Z&se=2027-01-20T19%3A31%3A16Z&sp=r&sv=2026-02-06&sr=b&sig=RFzKyqc7LI%2BOu4%2BVquCA5UP9/3/semqEficKuIgRUEQ%3D)

![70ae](https://copilot14.blob.core.windows.net/documents-and-assets/qdrant-ingest-docs/processed_images/visual_70ae_page_2.png?st=2026-01-20T19%3A26%3A16Z&se=2027-01-20T19%3A31%3A16Z&sp=r&sv=2026-02-06&sr=b&sig=ptqsmbz7ZebPTaWvZ1RC9InGSiBZYmBs8vbsqLbPmCI%3D)

After you send an email, you will get a ticket number and a technician will reply with the solution. If you need immediate support, you can also reach **“IT Support”** on Teams with the ticket number.
