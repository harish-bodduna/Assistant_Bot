# Signing into 1440 Foods with Microsoft Authenticator (Multi-Factor Authentication)

Two-factor authentication (multi-factor authentication) adds another authentication method to the sign-in process along with your password, making it much more difficult for a hacker or other malicious party to gain access to your account even if your password is compromised.

## Instructions

1. **Open the invitation email** from 1440 Foods (Teams channel or SharePoint) and select **Accept Invitation**.

   Use the sign-in credentials from the account that received the email.

## Frequently Asked Questions (FAQs)

### How can I change/add/delete multi-factor authentication methods?
Go to **aka.ms/mfasetup** to change/add/delete accounts from the MFA application. This is usually used if you want to add additional accounts, delete an inactive/wrong account, or make changes to an account to ensure seamless access to files/workspace at any given time.

### What is my Microsoft account password?
If your organization uses Microsoft, the password will be the same. If you are not sure what your password is, you can sign in via a code sent to your email.

### Will I have to set up authentication every time I access a shared file?
No. You will only have to set up authentication once. However, you will need to re-authenticate on each device and each browser you use to access a shared file/workspace.

### Are there other authentication methods besides scanning a QR code with the app?
Yes. Users can choose how they want to authenticate. Options include the **Authenticator app (preferred), email, security key, and office phone**. To learn more, visit **aka.ms/mfasetup**.

### Is it possible to reset all my authentication methods if I don't have access to any of them?
If you cannot access your chosen authentication methods, email **itsupport@1440Foods.com**. The team will respond and help resolve the issue.

### What happens if I do not receive a code?
When creating your account, it’s advisable to incorporate additional MFA methods (such as an authenticator app and SMS verification). If you have difficulty receiving a code or accessing any chosen options, contact **itsupport@1440Foods.com**.

### I already have another authentication app on my smart device. Why should I add the Microsoft Authenticator app?
The Microsoft Authenticator app uses push notifications for authentication, which is faster and more convenient than entering numeric codes used by other authenticator apps. Employees/IT support are well-versed in assisting users who use the Microsoft Authenticator app.

### What should I do if I get an authentication request and I'm not trying to log in?
Do not authorize the request. Decline it immediately and notify the IT Support team, as your password may be compromised. If you accidentally approve such a request, contact technical support right away: **itsupport@1440Foods.com**.

### How often will I be asked to re-authenticate?
If you’re using the same device, network, and browser (without private mode), and your account is not suspected of being compromised, you should only have to re-authenticate every **90 days**. If you clear your cache/browsing history or sign out of your applications, you will have to re-authenticate again.
